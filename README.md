# Extralt SDKs

The official Python and TypeScript clients for the [Extralt API](https://extralt.com/docs).

| Language | Package | Install |
| --- | --- | --- |
| Python 3.11+ | [`extralt` on PyPI](https://pypi.org/project/extralt/) | `pip install extralt` |
| TypeScript and JavaScript | [`extralt` on npm](https://www.npmjs.com/package/extralt) | `npm install extralt` |

## Documentation

- [Python SDK](python/README.md): usage and examples.
- [TypeScript SDK](typescript/README.md): usage and examples.
- [SDK guide](https://extralt.com/docs/using-the-api/sdks) in the Extralt docs.
- [API reference](https://api.extralt.com/docs) for every endpoint.
