# Extralt SDKs

Official Python and TypeScript clients for the [Extralt API](https://extralt.com/docs).

| Language | Package | Install |
| --- | --- | --- |
| Python 3.11+ | [`extralt` on PyPI](https://pypi.org/project/extralt/) | `pip install extralt` |
| TypeScript and JavaScript | [`extralt` on npm](https://www.npmjs.com/package/extralt) | `npm install extralt` |

Each package is versioned and released on its own; see [`python/`](python) and
[`typescript/`](typescript). To contribute, read [CONTRIBUTING.md](CONTRIBUTING.md). To report a
vulnerability, read [SECURITY.md](SECURITY.md).
