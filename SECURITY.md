# Security

Report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/extralt-ai/extralt-sdks/security/advisories/new),
not in a public issue. If you can't use it, email support@extralt.com with "Security" in the
subject.

Fixes ship in the latest release of each package. Vulnerabilities in the Extralt API itself are
welcome through the same channels.
